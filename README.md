# basemodo

This repository holds the releases of `basemodo`, the command that deploys and shares Apps on [Basemodo](https://basemodo.com). Its source is not here, and nothing but its releases is published here.

## Install

macOS and Linux:

```sh
curl -fsSL https://basemodo.com/install | sh
```

Windows (PowerShell):

```powershell
irm https://basemodo.com/install.ps1 | iex
```

Then follow [Getting started](https://basemodo.com/docs/getting-started).
